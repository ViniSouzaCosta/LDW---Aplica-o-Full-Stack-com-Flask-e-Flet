DigimonDex

Aplicação Full Stack desenvolvida para a disciplina de Linguagem de Desenvolvimento Web utilizando Flask, Flet e Tailwind CSS.

Sobre o Projeto

O DigimonDex é uma aplicação que permite consultar e cadastrar Digimons através de uma API REST desenvolvida com Flask. Os dados são consumidos por uma interface desktop construída com Flet. A aplicação demonstra conceitos de backend, frontend, consumo de APIs, documentação Swagger e validação de dados utilizando Pydantic.

Tecnologias Utilizadas

Flask

Desenvolvimento da API REST utilizando Blueprints.

Pydantic

Validação dos dados recebidos no endpoint POST.

Swagger

Documentação automática dos endpoints da API.

Flet

Interface desktop para interação com a API.

Tailwind CSS

Estilização da landing page.

Python

Linguagem utilizada em todo o desenvolvimento.

Funcionalidades

  • Listagem de Digimons cadastrados
  • Busca de Digimon por ID
  • Cadastro de novos Digimons
  • Validação de dados utilizando Pydantic
  • Documentação Swagger integrada
  • Integração entre backend Flask e frontend Flet

Endpoints Disponíveis

GET /digimons

Retorna a lista completa de Digimons.

GET /digimons/<id>

Retorna um Digimon específico pelo ID.

POST /digimons

Cadastra um novo Digimon na aplicação.

Como Executar o Projeto

Siga os passos abaixo para executar a aplicação:

  1. Clone o repositório do projeto.
  2. Instale as dependências necessárias.
  3. Execute o backend Flask.
  4. Acesse a documentação Swagger.
  5. Execute o frontend Flet.
  6. Cadastre e consulte Digimons.
cd backend
python app.py
                
cd frontend
python app.py
